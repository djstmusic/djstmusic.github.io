DJSTMUSIC PROFESSIONAL WEBSITE

1. Upload index.html and djstmusic-banner.png to the root of your GitHub repository.
2. Create a songs folder.
3. Put your MP3 files inside songs/.
4. The included player expects:
   songs/lowa-baha.mp3
   songs/nagin-bala-tatoo.mp3
5. Replace the # social-media links in index.html with your real Facebook,
   WhatsApp, YouTube and Instagram URLs.
6. Change 10K+ to your actual subscriber count if desired.

The website supports:
- Online MP3 playback
- MP3 download
- Web/mobile share button
- Song search
- Professional red/black DJ design
- Social media bar at the very top
- Subscriber badge at the top
- DJSTMUSIC banner/logo at the top of the home screen

Important:
GitHub Pages is static hosting. A truly live YouTube subscriber number needs
a YouTube API/backend or another trusted service. The supplied badge is
editable text, not a live counter.
